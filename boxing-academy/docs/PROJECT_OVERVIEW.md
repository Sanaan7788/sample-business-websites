# PROJECT_OVERVIEW

## 1. Product Summary

A modern, premium **boxing academy website** that functions as an automated
lead-generation and conversion engine — not a static digital brochure. The site
turns local search traffic into booked free-trial classes through a low-friction
funnel, builds trust with authentic coaching credentials and social proof, and
ranks for local "boxing gym near me"–style queries.

The MVP is a **mobile-first marketing site + lead-capture funnel** backed by a
small content database, with a path to grow into a CMS-managed, content-rich
local SEO property.

## 2. Business Goals

From `business-requirements.md`, the site must:

1. **Generate leads** — capture prospective members at the top of the funnel.
2. **Convert visitors into free-trial bookings** — the #1 conversion action.
3. **Build trust** — coaches' records, testimonials, success stories, reviews.
4. **Improve local SEO** — dominate local pack + organic for the target city.
5. **Allow easy content management** — non-developers can update content.

## 3. Primary User Actions (ranked)

1. **Book Free Trial** (primary conversion)
2. **View Class Schedule**
3. **Call the Gym** (click-to-call)
4. **Get Directions** (Google Maps)
5. **Become a Member** (view pricing / enquire)

Every page funnels toward action #1; the persistent sticky mobile CTA keeps it
one tap away at all times.

## 4. Target Audience

| Segment | Need the site must serve |
| :--- | :--- |
| Complete beginners | Reassurance (non-intimidating), clear "first class" path, FAQ. |
| Fitness enthusiasts | Conditioning/cardio framing, schedule flexibility, results. |
| Competitive fighters | Coaching pedigree, sparring/advanced programs, credibility. |
| Parents (youth boxing) | Youth program details, safety, age groups, trust signals. |
| Women in boxing fitness | Women's-friendly framing, dedicated program/landing page. |
| Weight-loss / conditioning seekers | Transformation proof, low-risk trial, pricing clarity. |

## 5. Value Proposition

Marry the **authentic grit of professional combat sports** (real coaches, real
records, real facility imagery) with the **frictionless onboarding of a modern
tech product** (fast mobile site, one-tap trial booking, transparent pricing).
A prospect should be able to land on the homepage, verify pedigree, see the
schedule, and book a free trial in the fewest possible interactions.

## 6. Success Criteria

**Business**
- Measurable free-trial lead submissions per week (primary KPI).
- High trial-to-form completion rate (low form abandonment).
- Local pack visibility + organic ranking for the target keyword set.

**Technical**
- Passing Core Web Vitals (LCP, CLS, INP) on mobile.
- Lighthouse: Performance ≥ 90, Accessibility ≥ 95, SEO ≥ 95.
- WCAG 2.1 AA accessibility.
- Valid LocalBusiness/HealthClub + FAQPage JSON-LD (Rich Results test passes).

## 7. Scope at a Glance

**In scope (MVP / P0):** marketing pages, free-trial lead-capture form (DB +
email), transparent pricing, filterable schedule, coaches & programs, contact
with map, FAQ, technical + local SEO baseline, sticky mobile CTA.

**Explicit non-goals (MVP):** merchandise store, online/on-demand classes,
member portal, complex payment system. (See `BACKLOG.md` — parked as P3.)
